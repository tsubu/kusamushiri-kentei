# 草むしり検定実技（プロトタイプ）

Three.js を使った、ブラウザで動く前進型ジャンプアクションの叩き台です。

「草むしり検定」をテーマに、ちいかわ風のキャラクターが森の中を走りながら草をむしり、岩や箱を避けてどこまで進めるかを競います。

## 遊び方

### Web で遊ぶ（GitHub Pages）

https://tsubu.github.io/kusamushiri-kentei/

GitHub Pages では PHP が動かないため、ランキングは**このブラウザの中（localStorage）**に上位10件まで保存されます（画面キャプチャつき）。

### 自分のサーバーで遊ぶ（MAMP など）


MAMP などのローカルサーバーのドキュメントルートに配置し、ブラウザで開いてください。

例：
```
http://localhost/game-test02/
```

※ `file://` では動作しません。必ず `http://` 経由でアクセスしてください。
※ Three.js は CDN（unpkg）から読み込みます。初回実行時はインターネット接続が必要です。

### 操作

- 左右移動：← / → または A / D
- ジャンプ：Space / ↑ / W（最大3回までストック、7秒ごとに1回回復）
- スマホ：左右タップで移動、画面上部タップでジャンプ
- 一時停止：Esc キー（または右上の Ⅱ ボタン）。停止中は「つづける／さいしょから／タイトルへ」を選べます。別のタブに切り替えると自動で止まります
- 落とし穴はジャンプで飛び越え、障害物は左右に避けよう

## ルール

- キャラクターは自動で前進し、速度は徐々に上がります。
- 地面の草に近づくと自動でむしります（たまに金色の高得点草もあります）。
- 岩や箱に正面からぶつかると転び、落とし穴に落ちるともがきます。1回目のミスはその場から再スタート、2回目のミスで検定終了です（画面上の「いのち」）。
- スタート時と再スタート時は 3・2・1 のカウントがあります。
- タイトル画面を7秒放置すると、20秒間のデモプレイが流れます（クリックかキーでタイトルへ。デモ中にミスしてもすぐにやり直します）。
- 経過時間に応じて段位が上がり、速度も段階的に上がります：
  - 検定落ち：40〜60 km/h（40秒間）
  - 5級：60〜80 km/h（40秒間）
  - 4級：80〜100 km/h（40秒間）
  - 3級：100〜120 km/h（30秒間）
  - 2級：120〜150 km/h（30秒間）
  - 1級：150 km/h〜、最高500 km/hまで徐々に加速

## ランキング（SQLite3／ブラウザ保存）

- 起動時に `api/ranking.php` に問い合わせ、PHP が動けばサーバー（SQLite3）、動かなければ（GitHub Pages など）このブラウザに保存するモードに自動で切り替わります。

- ゲームオーバー画面で名前（10文字まで）を入れて登録すると、`data/ranking.sqlite3` に保存されます（初回登録時に自動作成）。
- 並び順は「草むしりスコア → 走行距離 → 先に登録した人」（草むしり検定なので草が主役）。上位10件を表示します。
- ゲームオーバーの瞬間の画面キャプチャ（結果の帯つき JPEG）も一緒に登録され、ランキングにサムネイルで表示されます（クリックで拡大）。キャプチャは「画像をコピー」（クリップボードへ）か「画像を保存」（ダウンロード）で、Xへの投稿に添付できます。※ 画像のコピーは https か localhost で開いた場合のみ使えます。
- PHP の `pdo_sqlite` が必要です（MAMP の PHP には標準で入っています）。`data/` フォルダは Web サーバーから書き込める必要があります。
- `data/.htaccess` で DB ファイルへの直接アクセスを拒否しています（Apache の場合）。
- ※ スコアはブラウザから送られる値です。下の「セキュリティ対策」で大きな水増しははじきますが、完全には防げません。

## セキュリティ対策

- **スコアの偽造対策**：ゲーム開始時にサーバーが1回きりのトークンを発行し、登録時に「開始からの経過時間」で出せる距離・段位・草スコアを超える記録をはじきます（トークンは3時間で失効）。
- **APIの入口**：JSON以外の送信、別サイトからの送信（Origin / Sec-Fetch-Site）、640KBを超える送信を拒否。連投（5秒）・1日50件・トークン発行（10分60回）に上限。
- **入力の検証**：名前は制御文字・ゼロ幅文字などを除いて1〜10文字。画像は本物の JPEG（1280px・400KB以内）のみ保存。名前は画面に textContent で表示（HTMLとして解釈しない）。
- **ファイルの保護**：`.htaccess` で DB・鍵ファイル・隠しフォルダ（`.claude/` など）・`data/` への直接アクセスを拒否。接続元IPは秘密鍵（`data/secret.key`、自動生成）入りのハッシュで保存。
- **ブラウザ側**：CSP で読み込み元を自サイト・unpkg（three.js）・Google Fonts に限定。three.js は SRI（ハッシュ）で改ざんを検知。クリックジャッキング対策のヘッダーも `.htaccess` で付与。
- `index.html` の importmap を書き換えたら、CSP の `sha256-...` を計算し直してください（変えないと読み込みがブロックされます）。

### 公開するときの注意

- Apache（MAMP）以外のサーバーでは `.htaccess` が効きません。`data/` を外から見えない場所に置くか、同等の拒否設定をしてください。
- `data/` は Web サーバーから書き込み可能、かつ外部から読めない状態にしてください。
- 開発用の `php -S` は `.claude/dev-router.php` 経由で起動すると、同じく DB などへのアクセスを拒否します。

## Xへのポスト

ゲームオーバー画面の「𝕏 にポスト」で、検定結果・距離・スコア（登録済みなら順位）入りの投稿画面が開きます。

## ファイル構成

- `index.html` … ゲーム画面と UI
- `game.js` … Three.js ゲーム本体
- `style.css` … スタイル
- `api/ranking.php` … ランキングAPI（GET: 上位10件／POST: 登録）
- `api/shot.php` … 登録された画面キャプチャを返す（`?id=`）
- `data/` … ランキングDB（SQLite3）の保存先

## 今回の主な変更点

- ちいかわ風キャラクターの造形強化（まんまる白い体、小さな耳、ピンクのほっぺ、しっぽ）
- 森の中の背景（針葉樹・広葉樹・下草の茂み、木漏れ日、奥を霧に溶かす演出）
- 青空と雲のある空。180秒で 昼 → 夕焼け → 星空の夜 → 朝焼け → 昼 と時間帯が移り変わり、霧やライトの色も連動
- 道をレースゲームのように蛇行するコースに変更
- 地面を道に沿って曲がる1枚の連続メッシュにし、土の道テクスチャが蛇行に正しく沿うようにしました
- 草を7種類（草むら・ススキ風・双葉・オオバコ風・クローバー・ねこじゃらし・小花）の形に分けて描画
- キャラクターをトゥーン調＋輪郭線にし、大きな頭・小さな耳・ちょこんとしたしっぽの後ろ姿に
- 障害物に目立つマーカーを追加
- 定期的に落とし穴が出現（赤い輪と同じくらいの丸い穴が道幅のランダムな位置に。三角コーンで警告）
- 道の両サイドのキワにも岩・切り株・箱が出現
- 段位が上がるタイミングで、高い位置に張った「祝 ○級 昇級！」の横断幕（ガーランド旗つき）をくぐる演出
- 正面からの障害物衝突で転ぶアクション（目を回す星つき）、横からは跳ね返って続行
- 落とし穴に落ちると、ふちから顔を出してじたばたもがくアクション
- 2回ミスでゲームオーバー（1回目はカウントダウン後に再スタート、復帰直後は少し無敵）
- ちいかわ風のやわらかいタイトル画面と、自動操縦のデモプレイ
- ジャンプを最大3回ストック、7秒ごとに1回チャージ（画面下中央ゲージ）
- 速度上昇に合わせてFOV広がり・スピードライン強化など加速感エフェクト
- リングを削除、岩・箱を残しています
